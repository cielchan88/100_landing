API reference — the Ember-8 dialect
cls([c])clear the screen to color c (default 0)
pset(x,y,c) / pget(x,y)set / get a pixel. Out of bounds: ignored / returns 0
line(x0,y0,x1,y1,c)line (Bresenham)
rect(x0,y0,x1,y1,c) / rectfill(…)rectangle outline / filled
circ(x,y,r,c) / circfill(…)circle outline / filled
spr(n,x,y,[w,h],[flip_x],[flip_y])draw sprite n; w,h in sprites (default 1,1). Color 0 is transparent.
print(s,x,y,[c])3×5 pixel font, UPPERCASE only: A–Z 0–9 . , : ; ! ? - + / ( ) and space. Coerces with tostring. Default color 7
btn(i) / btnp(i)held / just-pressed. 0 ⬅ · 1 ➡ · 2 ⬆ · 3 ⬇ · 4 O (Z key) · 5 X (X key)
flr ceil rnd([n]) mid abs min max sqrthelpers. rnd(n) = random float in [0,n), default 1
t()seconds since cart start (float, 30 ticks = 1.0)
beep(freq,[dur],[wave])beeper: wave 0 square · 1 triangle · 2 noise. Browsers unlock audio after your first tap or keypress
_init() _update() _draw()your cart's hooks: once · 30×/s · after each update. Missing ones are skipped

Everything else is standard Lua 5.3: math.*, table.*, string.*, and friends. Ember-8 is its own dialect, inspired by fantasy consoles but not PICO-8-compatible — trig is standard radians via math.sin/cos. Cart globals persist between runs until you reload the page.

Ember-8 is a fantasy console: an imaginary machine whose strict limits — 128×128 pixels, sixteen colors, 8×8 sprites — are the whole point. Cartridges are written in real Lua and run on Fengari, a Lua VM implemented in JavaScript (the one external library, pinned from a CDN). The dialect is Ember-8's own, inspired by fantasy consoles but not PICO-8-compatible. Carts run entirely client-side in your own browser, like any code playground; nothing is uploaded and nothing is tracked. One honest quirk: a cart's globals persist between runs until you reload the page — very much in the retro spirit.
