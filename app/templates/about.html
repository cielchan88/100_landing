About this project

100 Days with Claude is a public commitment to ship one web project every day, for one hundred days in a row. No skip days, no cheat days, no rebrands of older work. Every day produces a new page that anyone can open in a browser.

Each project is built together with Claude (Anthropic). The point isn't polish — it's compounding. Small experiments stacked daily reveal what can actually be built in a single day, and what kinds of ideas are worth coming back to.

The site itself is deliberately simple: Flask, Jinja2, Tailwind via CDN, and Markdown for content. Light enough to host on a free PythonAnywhere tier, plain enough that nothing distracts from what's being made.
