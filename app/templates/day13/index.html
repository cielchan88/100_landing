Syntax cheat sheet (click to expand)

Each line is one relationship. Empty lines and lines starting with # are ignored.

A -> B          directed arrow
A -> B: label   directed with a label
A <-> B         bidirectional
A -- B          connected, no direction
A => B          strong arrow (accent style)
[Node]          emphasize a node (accent outline)
Name: text      give a node a description
